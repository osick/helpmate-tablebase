# `mine --dualfree` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `mine --dualfree` keeps only positions in which no two optimal solutions end in the same final position, on every mining surface.

**Architecture:** One core predicate `is_dualfree(solutions)` (distinct final boards == number of solutions). `MineFilter` gains `bool dualfree`; the scan enumerates solutions when it is set (exactly like `--starts`/`--ends`, so saturated positions are skipped and counted). `MineSet` gains `with_dualfree(keep)` for the shell. CLI, bindings, API and dashboard pass a boolean through.

**Tech Stack:** C++20 core (Catch2), pybind11 bindings (pytest), FastAPI (pytest), dashboard ES modules (`node --test`, Playwright).

**Spec:** `docs/superpowers/specs/2026-10-29-dualfree-design.md`

## Global Constraints

- Duals = two solutions whose final boards (placement + side to move) are identical. Dual-free = no such pair; one solution is dual-free.
- Saturated positions (count >= 255) are skipped by `mine` and counted in `skipped_saturated`.
- Not a theme: `probe`, `line`, `helpmate themes`, `detect()` unchanged.
- Build in the worktree with `g++-13` and offline FetchContent (`-DFETCHCONTENT_FULLY_DISCONNECTED=ON`, `FETCHCONTENT_SOURCE_DIR_*` = the main checkout's `build/_deps`); never `make test-api`/`test-web`/`install` (they pip-install into the user site) — test Python surfaces with `PYTHONPATH` and a separately built `_helpmate` module.
- Run builds and tests with `taskset -c 1-7,9-15`; never run several test processes in parallel (shared `/tmp` dirs).
- Commits end with the session's two attribution lines.

## Review Focus

1. A one-solution position must be kept by `--dualfree` — Task 1, `is_dualfree: one solution`.
2. A reordering of the same moves and a different route to the same mate are both duals — Task 1, the two `is_dualfree` fixtures.
3. `--dualfree` with no other filter on a table with saturated positions reports them as skipped, not as dual-free — Task 1, `mine --dualfree skips saturated positions`.
4. `--dualfree` combined with `--count 1` returns exactly the `--count 1` hits — Task 1.
5. The real KBBvk example (`8/6k1/6B1/8/8/B7/8/1K6 w`, dtm 9) is found by `--count 2 --theme model:2` and removed by adding `--dualfree` — Task 4.
